# Top Kabda — GitHub + Desktop

## تشغيل على سطح المكتب
1. شغّل `install-desktop.bat` على Windows.
2. سيتم نسخ المشروع إلى سطح المكتب داخل `Top-Kabda`.
3. لتشغيل الطباعة المباشرة: شغّل `run-print-bridge.bat`.
4. افتح `app/index.html` في Chrome/Edge.

## Firebase
- Firestore: الطلبات والإعدادات.
- Anonymous Authentication: مطلوب.
- Firebase Storage غير مطلوب.
- ضع محتوى `firestore.rules` في Firebase Console ثم Publish.

## GitHub Pages
المجلد `app` هو الواجهة الثابتة ويمكن نشره عبر GitHub Pages.
Print Bridge يعمل محليًا على كمبيوتر الكاشير ولا يُرفع إلى GitHub Pages.
